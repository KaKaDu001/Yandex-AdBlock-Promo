# 🚫 Yandex AdBlock Promo

Расширение для браузера, которое автоматически скрывает результаты поиска с пометкой "промо" на странице поиска Яндекса.

> Это форк проекта [Yandex-AdBlock-Promo](https://github.com/slavola59/Yandex-AdBlock-Promo) (автор: slavola59). Оригинальный код: https://github.com/slavola59/Yandex-AdBlock-Promo

## ✨ Основные возможности

* Автоматическое скрытие промо-результатов в поиске Яндекса
* Ответы Алисы (Alice AI) сохраняются и не скрываются
* Работает на всех доменах Яндекса (yandex.ru, yandex.com, ya.ru)
* Отображение количества скрытых промо-результатов на иконке расширения
* Поддержка динамически загружаемых результатов (AJAX)
* Работает в фоновом режиме без необходимости обновления страницы

## 🛠 Технические детали

* **Manifest V3** - современный стандарт расширений
* **Минимальные разрешения** - требуется только доступ к вкладкам
* **Высокая производительность** - оптимизированный код с использованием MutationObserver
* **Поддержка SPA** - отслеживает изменения URL и динамический контент

## 📦 Установка

### Из исходников

1. Скачайте или клонируйте репозиторий
2. Если иконок нет, сгенерируйте их:
   ```bash
   pip install Pillow
   python generate_icons.py
   ```
3. Откройте браузер (Яндекс.Браузер, Chrome, Edge и т.д.)
4. Перейдите в `yandex://extensions/` (или `chrome://extensions/`)
5. Включите "Режим разработчика" в правом верхнем углу
6. Нажмите "Загрузить распакованное расширение"
7. Выберите папку с расширением

### Из архива

1. Распакуйте архив `YandexClear-extension.zip`
2. Следуйте инструкциям из файла `ИНСТРУКЦИЯ_ПО_УСТАНОВКЕ.txt`

## 📋 Требования

* Браузер на базе Chromium (Яндекс.Браузер, Chrome, Edge, Opera и т.д.)
* Поддержка Manifest V3

## 🎯 Как это работает

Расширение использует несколько стратегий для обнаружения промо-результатов:

1. **Поиск элементов AdvLabel** - специальных меток Яндекса с текстом "Промо"
2. **Проверка классов** - поиск элементов с классами `Organic_withAdvLabel` и `Organic_withPromoOffer`
3. **Анализ DOM** - проверка структуры результатов поиска
4. **Защита ответов Алисы** - блоки ответа Алисы (Alice AI) определяются по маркерам и не скрываются

Расширение отслеживает изменения на странице в реальном времени и автоматически скрывает новые промо-результаты по мере их появления.

## 🔧 Разработка

### Генерация иконок

Если нужно пересоздать иконки:

```bash
pip install Pillow
python generate_icons.py
```

### Тестирование

1. Загрузите расширение в режиме разработчика
2. Откройте страницу поиска Яндекса (ya.ru или yandex.ru)
3. Выполните поисковый запрос
4. Проверьте, что промо-результаты скрываются
5. Проверьте, что на иконке расширения отображается количество скрытых результатов
